## 6주차수업내용
실습1: 자바스크립트 활용하기 -  JS 폴더를 생성하고 파일 복사한다. js에 다운받은 부트5(.js) 라이브러리를 복사하여 내부 로컬에서 연동한다. Html 파일 내에서 직접 js삽입(head)한다.
    <script>
    window.onload = function() {
    alert("메인 페이지 로딩 완료");
    }
    </script>
    를 넣어 페이지 새로고치면 "메인 페이지 로딩 완료"라는 팝업 창이 뜨게 된다. 왜냐하면 window.onload가 윈도우를 열(로드)때마다 뜨게 하는 것이기 때문이다.

실습2:  자바스크립트 활용하기 - "무료 플레이를 클릭하면 즐거운 플레이 되세요"라는 화면이 작게 뜨게 된다. 아까와 다른 이유는 이번 코드는 버튼을 클릭하였을때 뜨기로 되어 있기 때문이다. 그래서 새로고침을 한다고 했을때 뜨지 않고 무료 플레이 버튼을 눌러야 뜨는 것이다.

실습3: 자바스크립트 기본 문법1 - 블록 스코프 내에서만 접근이 가능한 if문이다. 첫번째 줄은 접근 가능하고 두번째 줄은 접근이 불가능하다. 세번째 줄은 에러가 나지 않는데 두번째 줄을 주석처리하고 페이지를 다시 로딩한다면 세번째줄도 에러가 나는 것을 볼 수 있다. 이렇게 두번째 줄을 주석을 해야 세번째줄이 에러가 나는 이유는 인터프리터 언어는 한줄씩 실행이 되기 때문이다. 즉, 두번째 줄에서 에러가 났기 때문에 멈춰서 세번째 줄은 실행되지 않은 것이다.

실습4: 자바스크립트 기본 문법2 - var은 고전적인 방식이다. 코드를 봤는데 똑같은 변수를 선언하고 값을 변경했는데 가능한 방법이다. let과 const는 되지 않는다. 호이스팅이라고 하는 것은 코드 실행전, 선언부를 해당 스코프 상단으로 끌어올린다.

실습5: LOL 기능 구현 중 실시간 챔피언 검색하기 - 검색창을 만들어뒀지만 아무런 반응이 없기 때문에 기능을 추가해야한다. 텍스트창 같은 것이 있는 것을 form창이라고 부른다. 이를 자바스크립트를 이용해 버튼을 누르면 실행이 되도록 본다. search를 searchForm으로 바꿔주고 id가 고유값이다. 그리고 search.js 파일을 만들어서 html 최하단에 연동한다. 그러고 페이지에서 검색을 해보면 오류가 난다. 다시 indev=x.html.dp 하단으로 가서  <script src="js/search.js"></script>를 해주면 오류가 나지 않는다. 내가 클릭을 하는 순간 타입 중 submit이 실행이 되는 것이다.

## 7주차수업내용
실습1: 실시간 챔피언 검색하기1 - Js 파일인 search.js 파일을 작성하고 html 최하단에 연동한다. DOM(Document Object Model)이라는 것을 추가하였는데 이것이 필요한 이유는 HTML 로딩을 위한 표준 구조와 트리 구조(DOM)로 변환하여 관리하는 역할을 하기 때문이다. 이것은 새로운 창을 열면서 검색 결과 출력한다. 입력: 이벤트, 검색 : 이벤트이고 F12 개발자 모드로 소스를 확인할 수 있다.

실습2: 실시간 챔피언 검색하기2 - 해당 코드를 뉴스 섹션 하단에 붙여넣기를 해준다. 하지만 아직 동작하지 않는 것을 볼 수 있다. 왜냐하면 검색을 해야 보여지게 되어있기 때문이다.
구현시키기 위해  search.js에 기존에 있던 코드는 주석처리 해주고 새로운 코드를 넣어준다. 문자열 앞에 이름이 들어가 있는 것을 볼 수 있는데 이것은 객체배열로 키와 값으로 되어 있어서 키로 검색읋 하면 빠르게 찾을 수 있다.

실습3: 아트록스 검색하면 아래에 있는 화면이 출력되는 것을 볼 수 있다. 기본 동작(코드)를 이해해 보자면, 현재 폼의 id는 searchForm(동일)이고 핵심 함수는 performSearch이다. 데이터 셋으로 부터 filter 조건 충족하고 키워드 가운데 출력해주는 것은 searchKeywordDisplay이다. 필터 결과 카운팅(숫자)는 0개인 경우 화면을 처리한다. 탭(기본) 전환은 switchCategory이고 카테고리 클릭(빨간 왼쪽 테두리)은 Type으로 판단한다.


<과제1>: 저번 과제에서 추가한 멜, 유나라, 자헨 카드에 이름, 역할, 난이도를 표시하고, 상세 보기 버튼을 누르면 Bootstrap 모달창을 통해 챔피언 상세 정보가 보이도록 구현하였다. 또한 search.js의 CHAMPIONS 배열에 신규 챔피언 데이터를 추가하여 검색창에 한글 이름 또는 영어 이름을 입력하면 해당 챔피언이 검색 결과 화면에 뜨도록 구현하였다. 

<과제2>: 검색 결과 화면이 표시된 상태에서 검색창을 공백으로 두고 Search 버튼을 클릭하면 showMainScreen() 함수가 실행되도록 구현하였다. 이 함수는 검색 결과 영역을 숨기고, 기존 메인 화면의 section들을 다시 표시한다. 빈 검색어 입력 시 검색 결과 화면에서 메인 화면으로 정상적으로 되돌아간다. 즉, 검색어가 없거나 공백인 경우에는 showMainScreen() 함수가 실행되어 검색 결과 화면을 숨기고 기존 메인 화면으로 돌아간다.


<소감>: 수업 시간에 아트록스의 이름을 검색해도 화면이 넘어가지 않아서 오류를 해결하느라 애먹었다. 그래도 수업이 다 끝난 후에 혼자 천천히 코드를 살펴보니 내가 상단과 하단에 같은 코드를 입력하여 꼬인 것을 알게 되고 화면이 정상적으로 뜰 수 있게 되었다. 이렇게 스스로 오류를 수정하며 해결해보니 실력이 조금이라도 성장한 기분이 들었다.

## 9주차수업내용
실습1: 다크모드 / 라이트 모드 전환 - toggle/js라는 파일을 만들어서 피피티에 있는 코드를 넣어주고 index.html에 방금 만들어준 toggle.js를 연결해준다. togggle.js에 추가한 코드는 기본에 있었던 다크 모드를 지워주고 필요한 속성들로 교체해주거나 콘텐츠가 라이트가 아니라 다크라면 기존에 있던 라이트 모드를 지워주고 다크 속성으로 교체해주는 일을 한다.

실습2: 데이터베이스 연동 - MySQL 데이터베이스를 프로젝트와 연동하는 과정을 진행하였다. 비밀번호를 설정했고 시작은 mysql을 입력하고 현재 데이터베이스 확인하고 싶으면 show databases; 라고 친다. 새로운 db생성(LOL 웹 서버 전용)하고 싶으면 create database lol;를 치고 MYSQL 내부, db 사용 및 테이블 보고 싶으면 use mysql;를 친 후 show tables;를 치면 된다. 마지막으로 최하단 user 테이블(구조 및 정보 조회)를 원한다면 desc user; 후에 select * from user; (root 계정 확인)을 치면 아래와 같은 화면을 볼 수 있다. 그리고 항상 명령어 마무리는 ;이므로 주의한다.

실습3: 데이터베이스 연동 (프로젝트 dev 보드를 통한 확인) - Quarkus의 Dev UI를 통해 데이터베이스 연동 상태를 확인하였다. 서버 실행 후 http://localhost:8080/q/dev/에 접속하여 DB connection pool과 MySQL 연결 정보를 확인하였고, champion 테이블이 생성되었는지 확인한 후 http://localhost:8080/champions 경로에서 챔피언 데이터가 JSON 형식으로 출력되는 것을 확인하여 데이터베이스와 웹 서버가 정상적으로 연동된 것을 아래 화면처럼 확인할 수 있었다.

<과제1>: 챔피온 검색 결과 모달창 띄우기 - 검색 결과 화면에서도 챔피언 상세 정보를 확인할 수 있도록 하기 위해 search.js의 CHAMPIONS 배열에 modalId 속성을 추가하였다. modalId에는 index.html에 작성된 각 챔피언 모달의 id 값을 저장하여, 검색 결과 카드와 기존 모달창이 연결되도록 하였고 검색 결과 카드 HTML에 상세 보기 버튼을 추가하고, Bootstrap의 data-bs-toggle="modal"과 data-bs-target 속성을 사용하였다. data-bs-target 값에는 각 챔피언 데이터의 modalId를 적용하여, 검색된 챔피언에 맞는 상세 모달창이 열리도록 구현하였다. 결과적으로 사용자가 검색창에 챔피언 이름을 입력하면 검색 결과가 출력되고, 검색 결과의 상세 보기 버튼을 클릭하면 메인 화면의 챔피언 카드와 동일한 방식으로 상세 정보 모달창을 확인할 수 있다.

<과제2>: 모든 페이지에 동일 적용하기 - 다크/라이트 모드 전환 기능의 JavaScript 호출 방식을 기존에는 HTML 버튼 내부에서 onclick="toggleTheme()" 방식으로 함수를 직접 호출했지만 이를 제거하고 이벤트 리스너 방식으로 변경하였다. toggleTheme() 함수는 body에 light-mode 클래스를 추가하거나 제거하여 테마를 변경하는 역할을 한다. theme-toggle-btn 클래스를 추가하고 toggle.js에서 addEventListener("click", toggleTheme)를 사용하여 버튼을 클릭하면 toggleTheme() 함수가 실행되도록 구현하였다. toggleTheme() 함수는 body에 light-mode 클래스를 추가하거나 제거하여 화면의 다크/라이트 모드가 전환되도록 하였다. 마지막으로 메인 페이지처럼 다운로드 페이지도 동일한 토글 버튼과 toggle.js 파일을 적용하여 두 페이지 모두에서 다크/라이트 모드 전환이 가능하도록 구현하였다.


<소감>: 처음에는 HTML, CSS, JavaScript 각각의 역할이 헷갈렸지만 검색 기능, 모달창, 다크/라이트 모드 전환을 직접 수정해보니 각 파일이 어떤 역할을 하는지 좀더 명확하게 알게 되었다. 
데이터베이스 연동 실습에서는 Champion.java, ChampionResource.java, DataSeeder.java의 역할을 구분하고 자바 객체가 데이터베이스 테이블과 연결되고 API를 통해 JSON 형태로 출력되는 흐름이 신기했다. 이번 과제를 통해 데이터를 저장하고 불러오는 웹 애플리케이션의 전체 구조를 경험하게 되어 흥미롭고 재밌었다. 그리고 그동안 페이지가 넘어가면 몇몇 페이지의 네비게이션바 비율이 조금씩 달랐는데 main.css와 download.css에 같은 버튼 스타일을 적용하여 두 페이지의 네비게이션 바, 토글 버튼 크기, 글자 크기가 동일하게 보이도록 수정했다.
